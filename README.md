# OCEAN'S WHISPER

### Lip Care & Beauty

Ocean's Whisper is a beauty and lip-care website created to showcase lip-care essentials and provide customers with a simple way to explore products and place orders.

## Features

- Responsive website design.
- Product showcase.
- Add-to-order functionality.
- WhatsApp ordering system.
- Direct WhatsApp contact.
- Live clock and date display.
- Mobile navigation menu.

## Technologies Used

- HTML5
- CSS3
- JavaScript
